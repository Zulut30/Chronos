# Chronos

Chronos — независимый форк [pingdotgg/t3code](https://github.com/pingdotgg/t3code) (MIT) на базе
**`v0.1.12-nightly.20261124.5209`** (`84e4264bb347e36e97f6c3bd95d666eecfa12e07`), переносящий
функциональность, внешний вид внутри окна, серверные правки и русский перевод Olympus один в один
поверх исходников T3, с установкой рядом с T3 и собственной лентой обновлений.

Проверка переноса с эталона 4774 на эту базу — в [отчёте по nightly 5209](../parity/upstream-5209.md).

Галерея артефактов открывается из SidebarChrome через штатный `openUrlInPreview` для треда и `__olyStudio.openInPanel` для диалога. Студия обслуживает карточки и подтверждение удаления, MCP передаёт открытие через процесс Студии и IPC главного окна. Для отдельно запущенного сервиса остаётся мост SSE Студии. [Артефакты](../parity/artifacts.md)

В настольном клиенте HostedBrowserWebview и диалог Студии создают отдельный guest. DesktopWindow связывает partition с обработчиком `chronos-artifact://` и preload из ресурсов. Документы страницы и MCP хранятся в одной SQLite.

Ярлыки Windows передают UUID через `--chronos-artifact`. Boot запускает отдельное окно до загрузки основного приложения, а DesktopClerk передаёт повторный запуск уже открытому Chronos. [Сравнение хостов на Windows](../parity/artifacts.md)

## Архитектура переноса Olympus (паритет 1:1)

Предыдущая попытка на базе 4838 с переписыванием функций Olympus на React и отдельным i18n-слоем
отклонена: внутри окна приложение должно вести себя и выглядеть точно так же, как Olympus поверх
T3 Code 4774.

Перенос разбит на четыре независимых потока; отчёты и списки изменений каждого потока хранятся в
`chronos/parity/`:

- **Упаковка Chronos** (`chronos/parity/packaging.md`) — отдельная идентичность на уровне ОС
  (имя продукта, иконки, заголовок окна, установка рядом с T3, профиль, `CHRONOS_HOME`,
  `chronos://`, `~/.chronos/bin/t3`, CI и лента обновлений). Не меняет содержимое внутри окна.
- **Клиентские модули Olympus** — перенос модулей и клиентских native-правок Olympus как есть. [Навигация между панелями настроек](../parity/client.md#навигация-в-настройках) подключена в `SettingsSidebarNav.tsx`. Фокус модальной доски задач удерживает [taskBoardFocus.ts](../../apps/web/src/chronos/olympus/taskBoardFocus.ts), подключённый из `appInit.tsx`.
- **Серверные правки и контракты** — перенос серверных и контрактных патчей Olympus как есть
  (OpenRouter в статистике, лимит CSS темы `THEME_CSS_MAX_LENGTH`, адаптер Antigravity CLI/children).
- **Перевод и паритет** — перенос русского перевода Olympus и проверки паритета
  (`.github/workflows/chronos-parity.yml`).

При первом запуске релизный Chronos устанавливает внешнюю тему **Olympus** в
`userdata/themes/olympus.json` и выбирает её для нового профиля. Днём используется исходный Olympus,
ночью — «Графит». Правила обновления и палитра описаны в [отчёте по теме](../parity/olympus-theme.md). Установщик включает семь HTTP-сервисов Olympus и OpenRouter MCP (stdio).
Chronos проверяет локальные порты после готовности Electron и запускает свободные сервисы
из ресурсов приложения. Профиль задаёт `CHRONOS_HOME`, по умолчанию `~/.chronos`.
Подробности — в [отчёте по сервисам](../parity/services.md).

Переход с Olympus 4774 на данные T3 в Windows описан в [инструкции по переходу и откату](../parity/switch-over.md).
