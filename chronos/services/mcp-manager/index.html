Серверы

    Изменения подхватят новые сессии агента — уже открытые чаты не перезапускаются. Выключенный сервер сохраняет все настройки. Серверы из плагинов и облачные подключения настраиваются в самих плагинах.

    Новый сервер MCP

    Как подключаться
    Переменные окружения ключи API и т. п., необязательно
    Заголовки HTTP например, Authorization, необязательно
    Для опытных: дополнительные поля конфигурации

    Перед изменением сохраняется резервная копия.

    Удалить сервер?

    Перед удалением сохранится резервная копия настроек. Если сервер нужен позже — просто выключите его переключателем.
