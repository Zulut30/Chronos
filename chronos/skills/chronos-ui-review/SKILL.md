name: chronos-ui-review
description: Проверяет готовую правку UI Chronos в установленном приложении или dev-клиенте, фиксирует воспроизводимые визуальные и поведенческие регрессии.
---

Выбери экземпляр Chronos по пути исполняемого файла и заголовку окна. На одном ПК может работать T3 с похожим интерфейсом. Сохрани окно, из которого ведётся работа. Для пакетной сборки сверь версию в «О программе» с проверяемым коммитом или тегом.

Повтори конкретное действие из задачи до видимого результата. Для визуальной правки сравни исходный и итоговый экран при одинаковой ширине, масштабе и теме. Для панели, которая зависит от локального сервиса, проверь, какой результат видит пользователь при доступном и недоступном сервисе. Когда затронуты общие токены, посмотри соседние компоненты в дневной и ночной теме Olympus, включая фокус и выделение.

Для каждого воспроизводимого дефекта укажи экран, действие, ожидаемый и фактический результат. При ревью с запросом на исправление перепроверь этот же сценарий после правки. Успешный тест компонента, скриншот dev-клиента и проверка установленной версии подтверждают разные вещи. В отчёте укажи фактический экземпляр, масштаб и пройденный сценарий.
