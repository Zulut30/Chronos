---
name: chronos-pc-control
description: Фоновая работа с приложениями и сайтами по запросу пользователя через локальный CLI Chronos. Используй для запуска программ, нажатия кнопок и заполнения форм.
---

В локальном окружении Chronos проверь наличие `CHRONOS_PC_CLI`. CLI принимает один JSON-объект в стандартный ввод и возвращает один ответ. Сохраняй выданный идентификатор сессии только в текущем треде. Запросу на подтверждение может потребоваться до двух минут. На Windows сохрани кодировку UTF-8 (Windows PowerShell 5: `$OutputEncoding = [System.Text.UTF8Encoding]::new($false)`).

```powershell
'{"op":"open","kind":"desktop","target":"notepad.exe"}' | chronos-pc
```

В POSIX shell используй `printf '%s' "$request" | chronos-pc`. Для уже открытого приложения запроси `attach` с его именем. Для сайта передай `{"op":"open","kind":"web","target":"https://example.org"}`. Веб-сессия использует отдельный headless-браузер. При отказе в доступе сообщи пользователю название программы или адрес сайта, который нужен в разделе «Управление ПК».

1. Запроси `{"op":"snapshot","session":"…"}`. Выбери элемент по его роли и названию. При нескольких окнах запроси `{"op":"windows","session":"…"}` и передай полученный `id` в поле `window` следующего снимка.
2. Передай ровно одну операцию с полученной ссылкой, например `{"op":"click","session":"…","ref":"…"}` или `{"op":"fill","session":"…","ref":"…","value":"Текст"}`. Для пароля и платёжных данных опусти `value`. Пользователь вводит значение в окне подтверждения Chronos.
3. Для нового временного документа в системном Блокноте Windows добавь в запрос `open` поле `"tempNote":true`. Возвращённый путь `document` принадлежит этому сеансу. Заполни текстовый редактор по ссылке, вызови `{"op":"save","session":"…"}` и проверь файл. Если меню поддерживает семантическое раскрытие, используй `expand` со ссылкой, затем `snapshot` с `"surface":"menu"`.
4. Получи новый снимок и проверь ожидаемый результат. После ошибки доставки сначала проверь состояние. Повторная отправка формы или сообщения может создать дубликат. Для сохранения файла проверь, что он записан по запрошенному пути.
5. В конце передай `{"op":"close","session":"…"}`.

Если дерево пусто, окно свёрнуто или нужное действие недоступно, сообщи, какое поле или действие недоступно. Для веб-содержимого можно открыть разрешённый адрес в отдельной веб-сессии. Для приложения используй его документированный API только в рамках запроса пользователя. Координаты, физические клавиши, фокус, буфер обмена, снимки рабочего стола и подключение к личному браузеру пользователя не подходят для фонового режима. Отклонение запроса и аварийная остановка завершают действие. Не повторяй его через сторонний CLI.

Подключение доступно агентам локального Chronos. Если переменная окружения отсутствует, объясни, что для этой операции требуется локальная сессия Chronos.
