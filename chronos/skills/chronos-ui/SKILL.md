name: chronos-ui
description: Изменяет и проверяет интерфейс Chronos на базе T3 4774 с модулями Olympus в отдельном окне Chronos рядом с T3.
---

Работай в репозитории Chronos. Архитектура переноса и точки подключения описаны в `chronos/README.md`
и отчётах `chronos/parity/`. Внутри окна Chronos должен воспроизводить Olympus 1:1 — не заменяй
модули Olympus самописным React-UI и не добавляй отдельный брендинг внутрь веб-клиента без явного
решения пользователя.

Перед изменением воспроизведи действие пользователя в отдельном экземпляре Chronos и зафиксируй
исходный вид. Окно T3/Olympus, из которого пользователь ведёт работу, оставь открытым и не трогай
его файлы (`~/.t3`, установленный `server.asar`, запущенные сервисы). Внешняя тема Olympus живёт в
`userdata/themes/` (не вшивается в бандл).

Проверь тот же сценарий после правки. Для диалога проверь открытие, Esc и возврат фокуса. На узкой
ширине проверь русские подписи. При зависимости от локального сервиса (`127.0.0.1:4517..4524`)
посмотри успешное действие и состояние при отключении сервиса, убедись, что внутренний origin
остался `t3code://app`.

Для отдельной приёмки готовой сборки используй `chronos-ui-review`. Для правок упаковки, иконок,
нативной рамки, заголовка окна, меню или профиля проверь установленное приложение Chronos рядом с T3.
