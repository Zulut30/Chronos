name: chronos-ui
description: Изменяет интерфейс Chronos в исходниках React/Electron и проверяет результат в отдельном окне Chronos. Используй для панелей, навигации, композера, меню и темы Olympus.
---

Работай в репозитории Chronos. Основные точки подключения описаны в `chronos/README.md`. Свои компоненты помещай в `apps/web/src/chronos/`. Для общих компонентов проверь существующие варианты в `apps/web/src/components/ui` и соглашения в `docs/internals/web-ui.md`.

Перед изменением воспроизведи действие пользователя в отдельном экземпляре Chronos и зафиксируй исходный вид. Окно T3, из которого пользователь ведёт работу, оставь открытым. Если правка затрагивает цвет или геометрию Olympus, меняй источник в `chronos/theme/`, синхронизируй встроенную тему через `node chronos/scripts/sync-theme.mjs` после её пересборки и проверь обе темы.

Проверь тот же сценарий после правки. Для диалога проверь открытие, Esc и возврат фокуса. Для команды проверь доступные входы из меню, клавиатуры и палитры. На узкой ширине проверь длинные русские подписи. При зависимости от локального сервиса посмотри успешное действие и состояние при отключении сервиса. Добавляй проверку именно для изменённого поведения.

Для отдельной приёмки готовой сборки используй `chronos-ui-review`. Покажи, что изменилось в самом окне Chronos. Укажи, на какой версии и в каком клиенте проверен результат. Для правок упаковки, шрифтов, нативной рамки, меню или системного масштаба проверь установленное приложение рядом с T3.
