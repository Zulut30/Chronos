# Клавиатуры Chronos

Работай на Windows-ПК, где открыт настольный Chronos. CLI запускается однократно через Node.js. Используй путь к `scripts/keyboard.cjs` рядом с этим файлом. CLI и приложение должны использовать один `CHRONOS_HOME`, по умолчанию это `~/.chronos`.

1. Выполни `node <путь-к-CLI> show` и `node <путь-к-CLI> actions`. Для списка профилей служит `profiles`. Профиль для настройки человек выбирает в «Настройки → Клавиатуры».
2. Уточни по описанию только неоднозначные позиции. `key1…key9` идут слева направо по рядам, центр — `key5`. У каждой ручки три независимых жеста. Верхняя — `upper-left`, `upper-press`, `upper-right`, нижняя — аналогично с `lower-`. Сохранённый сигнал относится к физическому экземпляру. Для нового макропада пройди обучение.
3. Подготовь JSON в UTF-8 во временном файле. Пример для запроса «центральная — новый Claude, верхняя ручка — громкость».

   ```json
   {
     "key5": {"id":"draft","arg":"Claude"},
     "upper-left": {"id":"volume-down"},
     "upper-press": {"id":"volume-mute"},
     "upper-right": {"id":"volume-up"}
   }
   ```

   Для модели можно указать точный идентификатор `экземпляр/модель`. Пустой параметр сохраняет штатный выбор нового черновика. Для ссылки указывай HTTP(S), для программы — полный локальный путь к .exe. Для снятия назначения передай `null`.
4. Выполни `node <путь-к-CLI> plan <файл.json>`. Покажи пользователю схему и русские названия изменённых назначений. Попроси подтвердить их в «Клавиатуры → Предложение ИИ → Подтвердить назначения». Назначения ОС дополнительно показывает нативный диалог. При устаревшем предложении перечитай активный профиль и построй свежий план.
5. Физические сигналы задаёт человек. Для коллизии двух ручек сообщи, какие позиции совпали. Профили записывает редактор Chronos после подтверждения. Пользовательские файлы, разрешения ОС и фирменный HID-канал напрямую не редактируй.
