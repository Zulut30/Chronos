# Trello в Chronos

В базе 5209 Trello использует тот же реестр, серверное хранилище секретов, привязки проектов и страницу задач, что и Linear. Один аккаунт Trello может видеть несколько рабочих пространств. В настройках выбирается доска, показанная вместе с названием её рабочего пространства. Для проекта можно выбрать несколько досок одного аккаунта. Первую используют инструменты агента, если при создании не указана другая.

| Возможность | Как работает Trello |
| --- | --- |
| Подключение | До сохранения пара API key и token проверяется через `members/me` и список доступных досок. Каждая дополнительная учётная запись получает отдельную запись в ServerSecretStore. При отключении удаляются её секрет и привязки. |
| Карточка | Номер `#idShort` показывается человеку, а ключ `shortLink` используется для чтения и привязки. Поддержаны название, Markdown-описание, метки, несколько участников, срок и HTTP(S)-ссылки вложений. Срок и ссылки отображаются отдельно от описания. |
| Статус | Открытая карточка принимает имя списка. Для архивации выберите «Архив», для восстановления — открытый список. Новая карточка попадает в первый открытый список доски. Флажок выполнения срока не архивирует карточку. |
| Страница задач | Поиск по названию, описанию, ключу и номеру, фильтры состояния, меток, исполнителей и участия, сортировка по созданию или изменению. Сохранённые виды Chronos сохраняют эти условия. «Упомянут» ищет точное @имя в описаниях и комментариях. Автор берётся из действия создания, когда оно доступно. |
| Ссылки | Ссылка `https://trello.com/c/<shortLink>` с необязательным названием открывает превью. Сервер узнаёт доску у Trello и выбирает привязанный проект и аккаунт. Если карточка доступна только на непривязанной доске, её можно читать. Перед записью доска проверяется повторно. |
| Инструменты | `list_issues`, `read_issue`, `create_issue`, `update_issue`, `comment_on_issue`, `set_issue_state`, `link_issue`, `unlink_issue`, `list_thread_issues`. В `update_issue` передаются только изменяемые поля. Пустой массив очищает метки или участников. `due: null` очищает срок. |
| Пагинация и лимиты | Карточки и действия читаются страницами по `before`. Сначала учитываются изменения на всей доске, затем отбирается страница для клиента. Комментарии открываются по 50. При HTTP 429 драйвер возвращает время следующей попытки, учитывая Retry-After и интервалы Trello. Запись автоматически не повторяется. |

## Отличия от Linear

Реакции, шаблоны, отдельная лента событий и статусы связанных pull request не поддержаны. Вложение со ссылкой на PR доступно как обычная ссылка. Вложения открываются на чтение. Комментарии можно читать и добавлять. Общий трекер Linear на базе 5209 также не предоставляет редактирование или удаление комментария. Архивация не даёт достоверной даты закрытия. Колонка с названием Done сама по себе считается открытым состоянием. Пикер показывает до 1000 меток с одной доски. Полная сортировка большой доски и поиск упоминаний требуют нескольких запросов. Для браузерного и настольного клиентов ключ и токен вводятся раздельно, для мобильного универсального поля — одной строкой `API_KEY:TOKEN`.

## Точки встраивания

Серверный драйвер и его HTTP-тесты находятся в `apps/server/src/chronos/issue-trello/`. Общие поля и парсер URL находятся в `packages/contracts/src/chronos/trello.ts`. Веб-компоненты настроек и полей карточки — в `apps/web/src/chronos/issue-trello/`. Полный перечень точек подключения к исходникам T3 приведён в [таблице форка](../README.md#trello).

## Проверка с реальным аккаунтом

1. Откройте [панель Power-Ups](https://trello.com/power-ups/admin), выберите свой Power-Up, откройте API Key и создайте ключ. По ссылке Token на странице ключа разрешите чтение и запись для тестового аккаунта.
2. В Chronos откройте настройки нужного окружения, раздел трекеров задач и строку Trello. Введите ключ и токен и нажмите «Подключить Trello». Проверьте имя аккаунта. Выберите доску тестового проекта. Для проверки изоляции добавьте ещё один аккаунт и привяжите другой проект.
3. Откройте «Задачи», выберите проект. Создайте карточку, назначьте двух участников и метку, смените список, сохраните вид с фильтром. Сверьте изменения в Trello. Архивируйте карточку и восстановите её через фильтр закрытых задач.
4. Поместите ссылку карточки в чат, откройте превью. Попросите агента привязать её к треду, прочитать, изменить заголовок и срок и оставить комментарий. Сверьте доску в треде, срок и комментарий в Trello. Добавьте в Trello вложение-ссылку и проверьте обновлённую карточку в Chronos.
5. Проверьте карточку с доступной, но непривязанной доски. Изменение через Chronos должно быть отклонено. Отключите тестовый аккаунт и убедитесь, что исчезли только его привязки.

Описание API и поведения постраничной выдачи — [Trello REST](https://developer.atlassian.com/cloud/trello/rest/), [nested resources](https://developer.atlassian.com/cloud/trello/guides/rest-api/nested-resources/), [rate limits](https://developer.atlassian.com/cloud/trello/guides/rest-api/rate-limits/).
