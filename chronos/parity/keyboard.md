# Клавиатуры

Настройки → Клавиатуры в настольном Chronos для Windows. Макропад SDINNOVATION SIDE-KEYBOARD (0816:2471) имеет сетку 3×3 и две ручки с нажатием, всего 15 позиций. На macOS, Linux и в браузере панель сообщает о поддерживаемой платформе.

## Как проверить на своём устройстве

1. Откройте раздел и включите макропад. Выберите SIDE-KEYBOARD в списке. Суффикс различает экземпляры. Дождитесь «Подключено».
2. Выберите центральную клавишу 5, нажмите «Запомнить сигнал» и нажмите её один раз. Назначьте «Новый черновик с моделью», введите Claude и сохраните. Клавише 1 таким же образом назначьте «Открыть доску задач». Проверьте индикатор обычной клавиатурой.
3. Выберите «Нижняя ручка · Вправо», включите обучение и поверните ручку на один шаг. Назначьте «Прокрутить вниз». Сравните с таким же поворотом верхней ручки. Сообщение о совпадении сохраняет прежнюю раскладку. Два одинаковых отчёта от одной коллекции невозможно различить программно.
4. Закройте настройки. В текущем проекте клавиша 5 открывает черновик, клавиша 1 — доску, в длинном треде нижняя ручка двигает ленту. Проверьте смену фокуса, отключение, повторное подключение в тот же USB-порт и выключатель. При смене порта может потребоваться выбрать экземпляр снова.
5. Для громкости назначьте жест и подтвердите действие Windows. Если прошивка сама посылает соответствующий media/volume usage, Chronos пропускает программный дубль. Пассивный Raw Input сохраняет исходный эффект прошивки. При проверке одобрений используйте одну видимую карточку в тестовом треде. Проверьте отказ и удержание клавиши на повтор.

## Хранение и выполнение

Активный профиль, выбор устройства, выключатель и разрешения ОС хранятся в `~/.chronos/userdata/keyboard/settings.json`, раскладки — в `profiles/*.json`. `CHRONOS_HOME` задаёт другой корень. Формат v2 хранит сигнал и действие отдельно, чтение v1 преобразует строковое действие. Запись идёт через временный файл и переименование. Предложение ИИ привязано к активному профилю и его ревизии. CLI и редактор используют один валидатор. CLI и каталог русских действий поставляются со скиллом `chronos-keyboard`.

Rust-процесс регистрирует Raw Input в отдельном скрытом окне. Родительский путь USB из дерева Windows объединяет только коллекции выбранного экземпляра. В профиль попадает SHA-256 пути. Сначала читается RID_HEADER, затем только пакет выбранной коллекции. Декодер обрабатывает клавиатуру, кнопки мыши, шаги колеса и отчёты Consumer Control ID 3 этого PID. Отпускание снимает удержание, повторы make отбрасываются. Для ввода нужны фокус главного окна и включённый профиль. В режиме настройки действия приостановлены. На blur, отключении, выходе приложения или закрытии родительского stdin хелпер завершается. Пустая шина не опрашивается по таймеру. Перечисление по запросу и повторное обнаружение по WM_DEVICECHANGE кратковременно запускают тот же бинарник.

Код распределён между `native/keyboard-input`, `chronos/keyboard`, `chronos/skills/chronos-keyboard`, `apps/{web,desktop}/src/chronos/keyboard` и контрактом `packages/contracts/src/chronos/keyboard.ts`. Узкие точки встраивания — главное окно Electron и preload, навигация настроек и Sidebar, кнопки подтверждений и голосовой ввод. Модель выбирается из доступных экземпляров в окружении проекта. Аварийная остановка запрашивает прерывание активных тредов с обычной проверкой прав. При нажатии действий ОС команда Windows передаётся через WM_APPCOMMAND, для программы используется путь без командной оболочки.

## Память макропада

Эта версия сохраняет раскладки на ПК. Будущий адаптер SDCX для FF00:0002 должен прочитать полный слепок именно выбранной платы и слоя, проверить полноту данных и сохранить резервную копию с возможностью восстановления. Перед записью нужно показать изменения и получить отдельное явное подтверждение пользователя. После записи нужно заново прочитать значения, сравнить с планом, проверить физические действия и при расхождении предложить восстановление из копии.
