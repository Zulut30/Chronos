# Chronos для macOS

Документ описывает установку, первый запуск, обновление, работу встроенных функций и ограничения Chronos на macOS (основная сборка — Apple Silicon `arm64`, вторичная — Intel `x64`).

## Установка рядом с T3 Code

Chronos спроектирован для работы параллельно с уже установленным на Mac **T3 Code** и не изменяет его файлы, настройки и базы:

| Параметр | T3 Code | Chronos |
|---|---|---|
| Приложение | `/Applications/T3 Code.app` (или `T3 Code (Nightly).app`) | `/Applications/Chronos.app` |
| Bundle ID (`appId`) | `com.t3tools.t3code` | `io.github.zulut30.chronos` |
| Профиль Electron (`userData`) | `~/Library/Application Support/T3 Code*` | `~/Library/Application Support/Chronos` |
| Данные сервера, БД, темы и сервисы | `~/.t3` | `~/.chronos` (переопределяется `CHRONOS_HOME`) |
| URL-схема обратного вызова | `t3code://` | `chronos://` |
| Шим CLI | глобальный `t3` в `PATH` | `~/.chronos/bin/t3` (привязан к `~/.chronos`) |

Миграция legacy-профиля T3 отключена, переменная `T3CODE_HOME` от установленного T3 игнорируется.

### Выбор образа

- **Apple Silicon (M1–M4 и новее):** `Chronos-mac-arm64.dmg` (или версионированный `Chronos-<версия>-arm64.dmg`).
- **Intel Mac:** `Chronos-mac-x64.dmg` (или `Chronos-<версия>-x64.dmg`).

Если на Mac с Apple Silicon случайно установлена сборка `x64` (под Rosetta), Chronos покажет предупреждение в боковой панели, а кнопка скачивания обновления автоматически предложит образ `arm64`.

## Первый запуск (снятие карантина)

Сборки Chronos не подписаны платным сертификатом Apple Developer ID и не нотаризованы в Apple. В CI для `Chronos.app` выполняется:

1. Запись корректного хэша `ElectronAsarIntegrity` для `Resources/app.asar` в `Contents/Info.plist`.
2. Очистка лишних расширенных атрибутов и ad-hoc подпись вложенных Mach-O бинарников в `Contents/Resources/` и всего бандла (`codesign --force --deep --sign -`).
3. Строгая проверка целостности подписи (`codesign --verify --deep --strict --verbose=2`) на итоговых `.zip` и `.dmg`.

Несмотря на корректную ad-hoc подпись, macOS помечает скачанный из браузера `.dmg` атрибутом `com.apple.quarantine`, из-за чего Gatekeeper при открытии сообщает, что приложение «повреждено» или получено от неизвестного разработчика (в macOS 15/26 обход через правый клик → «Открыть» больше не работает для таких сборок).

Порядок установки и первого запуска:

1. Откройте скачанный `.dmg` и перетащите **Chronos.app** в папку **Программы** (`/Applications`).
2. Откройте **Терминал** и снимите атрибут карантина с установленного приложения:
   ```sh
   xattr -cr /Applications/Chronos.app
   ```
3. Запустите **Chronos** из «Программ» или Spotlight.

Если переустановить Chronos из нового `.dmg`, команду `xattr -cr /Applications/Chronos.app` нужно повторить перед первым запуском обновлённой версии.

## Обновление

Squirrel.Mac (движок автообновления Electron на macOS) отказывается устанавливать обновления без подписи сертификатом Apple Developer ID. Поэтому на macOS Chronos работает в прозрачном ручном режиме без ошибок и повторных попыток Squirrel.Mac:

1. Приложение само проверяет ленту `nightly-mac.yml` из релизов `Zulut30/Chronos`.
2. Когда выходит новая версия, в боковой панели и в **Настройки → Общие** появляется кнопка **«Скачать DMG»** (и список изменений). Удалённые обновления и «Обновить всё» не пытаются перезаписать macOS-приложение через Squirrel.Mac.
3. Нажатие **«Скачать DMG»** открывает в браузере прямую загрузку образа `Chronos-<версия>-<архитектура>.dmg` для текущей архитектуры Mac (`arm64` на Apple Silicon, включая запуск под Rosetta; `x64` на Intel).
4. Для установки обновления закройте Chronos, откройте скачанный `.dmg`, перетащите `Chronos.app` в `/Applications` с заменой, затем выполните:
   ```sh
   xattr -cr /Applications/Chronos.app
   ```
5. Данные, чаты, настройки, ключи и артефакты в `~/.chronos` и `~/Library/Application Support/Chronos` сохраняются.

## Работа функций Chronos и Olympus на macOS

- **Локальные сервисы Olympus (sidecars):** все 7 HTTP-сервисов (`4517–4524`: задачи, скиллы, файлы, Студия, интеграции, менеджер MCP, olympus-hub) и `openrouter-service` (stdio) запускаются из `Chronos.app/Contents/Resources/chronos-services` через встроенный Node-рантайм (`ELECTRON_RUN_AS_NODE=1`) и хранят данные в `~/.chronos`.
- **API-ключи (`integrations-service`):** вместо реестра Windows сохраняются атомарно в локальный файл `~/.chronos/integrations-service/keys.env` с правами доступа `0600` (каталог `0700`).
- **Выгрузка Claude при простое:** дерево процессов читается через системную утилиту BSD `ps` с раздельными флагами `-o pid= -o ppid= -o pgid= -o lstart=` и `LC_ALL=C`, поэтому смена системного языка macOS не ломает разбор времени старта процесса.
- **Управление ПК (`agent-desktop`, `agent-browser`):**
  - В сборку для macOS (`arm64` и `x64`) включены нативные компоненты `agent-desktop`, `agent-desktop-macos-helper` и `agent-browser`.
  - Если компонент `agent-desktop` отсутствует или недоступен, раздел **Настройки → Общие → Управление ПК** скрывает форму включения и показывает понятное пояснение на русском языке.
  - Для управления окнами приложений выдайте Chronos разрешение в **Системные настройки → Конфиденциальность и безопасность → Универсальный доступ** (и при необходимости **Запись экрана**).
  - Сочетание аварийной остановки: `⌘ + Option + Shift + F12`.
- **Артефакты:** полноценно работают внутри Chronos — в диалоге Студии и в правой панели треда, с изолированным `webview`, SQLite-базой и темой оформления.
- **SSH-туннели в менеджере скиллов:** активные туннели `-L <порт>:127.0.0.1:3773` определяются через `ps -A -ww -o args=`.

## Что не поддерживается на macOS

Следующие возможности относятся только к Windows или требуют платного аккаунта Apple Developer и на macOS отключены без ошибок:

- **Автоматическая установка обновлений (Squirrel.Mac):** без сертификата Apple Developer ID обновления скачиваются и ставятся вручную из `.dmg`.
- **Нотаризация и Apple Passkeys:** требуют подписи Developer ID и provisioning profile.
- **WSL-бэкенд:** специфика Windows.
- **Отдельный скрытый рабочий стол для «Управления ПК» (`private-desktop.exe`) и «временный Блокнот»:** работают только в Windows; на macOS управление работает с окнами текущего рабочего стола после выдачи прав «Универсальный доступ».
- **Ярлыки артефактов на рабочем столе и в меню «Пуск» (`.lnk`):** кнопка «Установить как приложение» скрыта на macOS; артефакты открываются внутри Chronos.
- **Подключение макропада / Raw Input клавиатуры (`chronos-keyboard.exe`):** только Windows; раздел **Клавиатуры** показывает понятное сообщение о недоступности на macOS.
- **SSH-сервер CLI для Intel macOS (`darwin-x64`):** Node SEA не поддерживает `darwin-x64`; в релиз входит CLI-архив для Apple Silicon `t3-<версия>-darwin-arm64.tar.gz`.

## Автоматическая проверка в CI

- `.github/workflows/chronos-desktop.yml`: после сборки `mac-arm64` и `mac-x64` проверяет наличие и исполняемость `chronos-services` и `chronos-pc`, запускает `services.test.mjs`, а затем проверяет `codesign --verify --deep --strict --verbose=2` и совпадение `ElectronAsarIntegrity` в `Contents/Info.plist` внутри готовых `.zip` и `.dmg`.
- `.github/workflows/chronos-smoke.yml` (`smoke-macos`, раннер `macos-26` arm64): скачивает `chronos-mac-arm64` из указанного `desktop_run_id`, монтирует `.dmg`, устанавливает `Chronos.app`, проверяет подпись, `ElectronAsarIntegrity`, нативные бинарники `chronos-pc` и формат BSD `ps`, запускает приложение с CDP, проходит все экраны, сервисы Olympus, настройки чата, управление ПК, артефакты, проверяет отсутствие ошибок консоли и лишнего английского текста, и загружает скриншоты в артефакт CI `chronos-smoke-macos-report-<desktop_run_id>` (в репозиторий скриншоты не попадают).
