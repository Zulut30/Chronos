# Артефакты

Промежуточная реализация. Эталон описывает публикацию HTML, обновления, просмотр истории, комментарии, загрузки и живые данные через MCP. [Документация Claude Code](https://code.claude.com/docs/en/artifacts)

| Функция | Аналог Chronos | Статус |
|---|---|---|
| Публикация, обновление и чтение | artifact_publish, artifact_read в MCP Студии | Текстовая карта файлов. Каждая публикация создаёт версию |
| История | artifact_history | Чтение прошлых версий и защита от устаревшей записи |
| Поиск и закрепление | artifact_list, artifact_pin | Список и флаг закрепления в SQLite. Интерфейс предстоит реализовать |
| Открытие, удаление и ассеты | Правая панель, подтверждение, библиотека | Предстоит реализовать |
| API страницы | Данные, возможности, файлы, вопросы агенту | Предстоит реализовать |
| Совместное редактирование | Комментарии и наблюдение | Предстоит реализовать |
| Установка приложения | Ярлыки и отдельное окно | Сравнение Electron и WebView2 ещё не проведено |

Хранилище открывается при первом обращении к инструменту. Обработчики входят в существующий MCP Студии общего хаба. Публикация сохраняет метаданные и файлы одной транзакцией SQLite под userdata/artifacts. Проверка ожидаемой версии выполняется после получения блокировки записи.

Фаза 2 включает шаблоны слайдов, документов, дашбордов и таблиц.
