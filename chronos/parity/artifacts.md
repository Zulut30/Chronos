# Артефакты Chronos

[Эталон Claude Code](https://code.claude.com/docs/en/artifacts) и локальная реализация в MCP Студии.

| Возможность | Реализация MVP |
|---|---|
| Создание и обновление | `artifact_publish` сохраняет метаданные, разрешения и карту файлов транзакцией SQLite. `source` связывает версии, `expectedVersion` защищает от потери правок |
| Галерея и показ | Ссылка «Артефакты» в сайдбаре, поиск по названию и описанию, закрепление, карточки. `artifact_open` использует мост Студии и текущую правую панель. Без треда Студия открывает диалог |
| История и удаление | Галерея и MCP используют одни операции хранилища. Восстановление копирует снимок в новую версию. `artifact_delete` запрашивает подтверждение в галерее. Подтверждение относится к конкретной версии |
| Рантайм | Настольный guest или отдельный BrowserWindow. UUID задаёт origin `chronos-artifact://<id>` и постоянный partition. Sandbox и contextIsolation включены. CSP и фильтр сети разрешают HTTPS на cdnjs.cloudflare.com, cdn.jsdelivr.net и unpkg.com |
| Возможности | `window.chronos` и `window.claude` предоставляют объявленные theme, db, files.open и files.save. Диалоги выбирают файл по действию пользователя. Документы разделены по UUID, доступны странице и агенту через семь методов. Batch атомарен |
| Ассеты | Строки UTF-8 и объекты base64. Ограничения на декодированные данные составляют 15 МиБ для файла, 16 МиБ для всей страницы и 255 файлов вместе с index.html. Версии сохраняют исходные байты |
| Установка Windows | Кнопка в просмотрщике сохраняет палитру Olympus для отдельного окна и создаёт именные ярлыки в «Пуск» и на рабочем столе. Значок берётся из карточки. Аргумент запуска содержит UUID. При открытом Chronos окно использует его процесс, при закрытом запускается до загрузки main и сервисов |
| Скилл агента | [Публикация, API и оформление](../skills/chronos-artifacts/SKILL.md) |

## Выбор хоста Windows

Одна VM Windows 2025, три запуска каждого варианта в шести отдельных профилях. Electron 44.10.1 с BrowserWindow и отдельным partition и Rust/wry с системным WebView2 открывали одну HTML-страницу. Отсчёт от создания процесса до сообщения PerformanceObserver о first-contentful-paint. Память суммируется по дереву процессов спустя 1,5 с после сообщения. База холодного запуска — ноль процессов приложения. Измерялся изолированный оконный хост без основного интерфейса Chronos. [Прогон и исходные результаты](https://github.com/Zulut30/Chronos/actions/runs/45643231481)

| Хост | Private bytes, медиана, МиБ | Working set, медиана, МиБ | Первый кадр, три запуска, мс | Медиана, мс |
|---|---:|---:|---|---:|
| Electron BrowserWindow | 88,2 | 261,2 | 894 / 502 / 485 | 502 |
| Rust WebView2 | 91,5 | 278,0 | 6037 / 922 / 827 | 922 |

Основной хост — BrowserWindow. Он занял меньше памяти по обоим счётчикам и раньше показал содержимое. Первый запуск WebView2 на VM занял 6037 мс. Прототип остаётся в `native/artifact-host` для повторения замеров.

## Проверка

В `Chronos checks` тесты под Electron проверяют исторические версии, границы файлов, двоичный MCP, изоляцию БД, атомарность и политику ресурсов. В Windows smoke при включённых сервисах отдельно проверяются показ страницы, запись из sandbox в БД, доступные возможности, создание ярлыков и холодный запуск из ярлыка.
