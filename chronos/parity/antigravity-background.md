# Фоновая работа Antigravity

После ответа на `session/prompt` Antigravity может дождаться команды или таймера и продолжить через тот же канал ACP. Chronos показывает ожидаемые задачи открытого хода в панели фоновой работы. Когда агент начинает отвечать уже после завершения хода, клиент принимает его события в продолжение. Для этого второй `session/prompt` не нужен. Долго молчащая команда остаётся фоновой до фактического завершения. Stop прекращает ожидание.

Адаптер передаёт сведения о работе в проверку выгрузки ACP. Стенд `chronos/scripts/bench/agent.mjs` в режиме `antigravity-background` завершает запрос, затем выдаёт собственное обновление, таймер и результат. Интеграционный тест запускает этот процесс через stdio и проверяет завершение и отмену.

## Песочница

Для обычного хода в режиме «Полный доступ» драйвер явно передаёт `--sandbox=false --dangerously-skip-permissions` при запуске. Перед ходом ACP устанавливает native `default`, в том числе после сохранённого выбора `auto`. Подтверждения остаются под управлением политики треда. В режиме «Авто» используется native Auto, когда агент его поддерживает. Настройки экземпляра показывают политику терминала работающих тредов. Права пользователя ОС и отдельные правила инструментов MCP продолжают действовать.

## Подтверждения

Codex передаёт в `turn/start` политику `never` и `dangerFullAccess` для обычного полного доступа. Если старый app-server повторяет локальный запрос выполнения команды, Chronos применяет решение действующего хода и записывает его в ленту. ACP записывает в ленту разрешения, выданные действующей политикой. OpenCode v1/v2 отвечает на повторный запрос для распознанного локального инструмента, если этой же операции уже выдано разрешение в правилах текущей сессии. При ошибке передачи решения запрос остаётся доступным. Провайдеры используют собственные API для применения прав. Внешняя авторизация, правила организации и запрос повышения прав UAC требуют отдельного решения. Установленный Olympus может показывать запрос Codex на Windows даже при выбранном полном доступе.

## Квоты аккаунта Google

В Olympus 4774 лимиты поступали из внутренних API Google. Chronos читает окна аккаунта через штатную команду CLI `agy -p /usage --output-format json`. Google добавил ответ без хода модели в версии 1.1.11. Драйвер проверяет версию перед запуском команды. Для print-режима создаётся временный домашний каталог со ссылкой на ACP-профиль выбранного экземпляра. Вход выполняется через настройки провайдера в соответствующем окружении. Периодическая проверка доступности провайдера не запускает команду квот.
