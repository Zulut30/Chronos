Оба инструмента дают агенту один цикл «снимок → действие по ссылке → проверка». Сборка сверяет SHA-256 закреплённых релизных файлов до распаковки. На Windows и macOS вместе с CLI в установщик входят оригинальные лицензии. Указанные размеры — размеры файлов поставщика, измерение памяти приведено отдельно.

## Настройки и процессы

В настольном клиенте откройте **Настройки → Общие → Управление ПК**. Выберите приложения и адреса сайтов или разрешите все. Примените настройки. При действии внизу окна появится индикатор, из него можно открыть запросы на подтверждение. Остановить все действия можно через индикатор или Ctrl / ⌘ + Alt + Shift + F12. Настройки сохраняются в профиле Chronos. Журнал хранит последние 100 результатов без текста полей и адресов.

Скилл вызывает локальный командный клиент из окружения backend. Запрос проходит через общий обработчик в Electron main. Проверки настроек, разрешённых целей и подтверждений выполняются перед запуском нативного инструмента. Для неопределённого назначения кнопки применяется обязательное подтверждение. Только доверенное главное окно принимает решение о запросе. Данные поля передаются через stdin. Отключение разрывает активные соединения. На SSH и WSL управление рабочим столом хоста из этой функции недоступно.

Права на произвольный shell в ОС задаёт сам провайдер. Политика Chronos охватывает его интерфейс управления ПК. Для изоляции произвольного кода провайдера требуется системная песочница.

## Приёмка

На Windows x64 проверялся классический системный Блокнот. Win32-помощник создаёт отдельный рабочий стол через CreateDesktop и запускает там приложение и agent-desktop. Пользовательский рабочий стол остаётся активным. После создания процесса помощник ждёт WaitForInputIdle: первоначальный вариант закрывал дескриптор слишком рано, и EnumWindows не видел окно. Блокнот получил текст через UIA SetValue. Провайдер его меню вернул ACTION_FAILED при попытке Expand. Для временного документа Chronos находит пункт сохранения по Ctrl+S в меню именно созданного окна и посылает ему WM_COMMAND. В smoke результат независимо прочитан с диска. Заполнение двух полей WinForms проверено по содержимому, записанному обработчиком кнопки в тестовом приложении.

| Изолированный Windows-раннер, три снимка формы | 1 | 2 | 3 |
| --- | ---: | ---: | ---: |
| Пик рабочего набора agent-desktop, МиБ | 17,42 | 17,64 | 18,22 |
| CPU процесса за команду, мс | 62,500 | 31,250 | 46,875 |

После завершения команд процессов agent-desktop было 0. Проверка курсора, активного окна и фокуса клавиатуры собрала 937 отсчётов без изменений. Значения относятся к нативному CLI. В эти значения не входит память Chromium, оболочки Chronos, открытых приложений и помощника, удерживающего приватное окно. Веб-тест заполнил обычное и защищённое поля, нажал кнопку и сверил значения на независимом локальном HTTP-сервере. Для защищённого поля сервер получил значение, переданное через интерфейс подтверждения. [Изолированный прогон](https://github.com/Zulut30/Chronos/actions/runs/45649965773/job/139331474224)

При завершении приватной сессии Windows закрываются только запущенные ею процессы. Перед завершением сохраните документ. В режиме подключения к уже открытому окну используются семантические действия; опубликованные замеры относятся к отдельному рабочему столу. Установщик также содержит скилл в `resources/chronos-pc/skills/chronos-pc-control`. На Windows поддерживаются штатные пакеты Chronos x64, на macOS — arm64 и x64. Если на компьютере нет Chrome, Edge или Chromium, для веб-сессий потребуется совместимый браузер. macOS требует разрешения Accessibility. Его выдачу и взаимодействие с реальными macOS-приложениями этот Windows-тест не проверяет.
