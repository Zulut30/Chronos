# Olympus в релизном Chronos

У темы один идентификатор `olympus`. Дневная палитра, общий CSS, дневные правила и изображения взяты из прежнего Olympus. Ночью используется выбранный вариант B «Графит». Холст имеет цвет `#101216`, карточки — `#1D2229`, приподнятые панели — `#262C36`, контур — `#3B4351`. Декоративные панели используют `--oly-glass`, поэтому переменная карточек `--card` снова получает цвет поверхности. У встроенного кода собственная подложка `#242A33` и текст `#E4D4AA`. Наименьший контраст среди проверенных в аудите текстовых пар — 4,82:1 у плейсхолдера на приподнятой панели. Тема оформляет оболочку Студии, содержимое её iframe оформляет сам сервис.

## Установка и обновление

Сборщик копирует `chronos/brand/themes/olympus.json` в `resources/chronos-themes/` для всех платформ. До запуска локального сервера Electron устанавливает копию в `userdata/themes/` выбранного профиля Chronos. Сервер публикует файл через существующий каталог тем, клиент применяет его обычным механизмом выбора палитры. Для нового профиля Chronos задаёт `defaultTheme` равным `olympus`, режим освещения следует системной настройке.

Существующий файл обновляется только при совпадении SHA-256 с исходным экспортом Olympus (известны варианты переводов строк CRLF и LF). При правках пользователя или нехватке места новая версия доступна отдельно в `userdata/theme-updates/olympus-graphite.json`. Её можно сравнить со своей темой и скопировать в `userdata/themes/olympus.json` вручную. Каталог обновлений находится за пределами списка тем и его бюджета в 2 МиБ. Настройки существующего профиля сохраняются.

Эталон Olympus 4774 остаётся исторической точкой сравнения. Для ночи ожидается смена палитры на всех экранах, включая карточки, композер, доску задач и рамку Студии. Эти различия не требуют расширения пиксельных масок.
