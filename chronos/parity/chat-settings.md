# Настройки чатов Olympus на базе 5209

Путь в веб-клиенте и приложении Electron — **Настройки → Внешний вид → Интерфейс**. Цветной текст и скачивание видны сразу. Остальные параметры находятся в «Дополнительно» и доступны через поиск настроек. Они сохраняются в localStorage текущего клиента. По умолчанию запускаются все модули и используются сохранённые значения Olympus.

Для каждого переключателя модулей ключ `chronos.olympus.<id>` со строкой `0` означает «выключен». При включении ключ удаляется. Первым из трёх ESM-ассетов (пролог, иконки, Markdown) окно фиксирует общий набор выключенных модулей. Изменение действует после перезапуска или перезагрузки окна. В режиме разработки применяется та же проверка перед выполнением отдельных файлов. Общие точки Markdown в web получают `undefined` при выключении цветов, поэтому оба рендерера пропускают pre/post и используют обычную схему санитайзера.

## Опись модулей

Ключи в таблице содержат строки, если явно не указан JSON. Пометка «оставлен» означает, что отдельного выключателя в «Интерфейсе» нет.

| 17-servers | Подписи процессов в карточке серверов треда | Нет | Самостоятельное оформление с подпиской на ядро. Оставлен. |
| 10-plan-mode | Пять режимов ответа | `oly-plan-v2:thread:<id>` и `oly-plan-v2:draft:<id>` — `default/plan/brainstorm/bug-hunter/design-plan`. `oly-plan-v2-migrated=1` и старый `oly-plan` нужны для миграции. | Переключается. При отключении отправка и возобновление используют штатный режим T3. Для запуска задачи именно в режиме планирования нужен включённый модуль. Режим конкретного чата выбирают в его композере. |
| 92-studio-shell | Панель Studio поверх окна | Нет | Оболочка нужна для резервного открытия Studio из 60. Оставлена. |

| 88-rich-text | Цвета текущей темы, копирование выделения и сообщения с HTML | Нет | Переключается вместе с 88-rich-markdown.chat. |
| 88-rich-markdown.chat | Обрабатывает разрешённое оформление по обе стороны санитайзера | Нет | Тот же флаг 88-rich-text для Markdown и Words. |
| extras | Кнопки навыков и режимов, стили и управление плавностью | Нет настроек чата в localStorage | Смешанный модуль. Вызовы UI режима ответа опциональны. Оставлен. |
| 20-speed | Токены в секунду и статистика по моделям | `oly-speed-v4` — JSON с версией, замерами, уже учтёнными событиями и автоматически определёнными параметрами моделей. Читает v2/v3 для миграции. | Переключается. Сохранённые замеры остаются на устройстве. |

| 24-thread-details | Лимиты и связанные чаты в карточке треда | Своих ключей нет | Для дополнительных сведений опционально читает 25 и 93. Видимость пунктов уже настраивается в «Детали треда». Оставлен. |
| 25-bg-tasks | Фоновые задачи и их действия в чате | `oly-bgtasks-seen` — JSON-объект времени просмотра по ключу | Источник дополнительных данных для 24. Оставлен. |
| 26-notifications | Уведомления о ходе и запросах в фоновых чатах | `oly-notifications-mode` — `all/minimized/silent/off`, по умолчанию `all`. `oly-notifications-active` и `oly-notifications-posted` — служебные JSON-массивы для координации окон. | Отдельный выключатель при включённом 22. Режим уведомлений применяется сразу через обработчик storage. Сам 26 не рассылает уведомления о пороге квоты. |
| 28-model-account | Почта и тариф учётной записи в меню моделей | Нет | Использует ядро. Оставлен. |
| 30-tasks | Упоминания задач и запуск чата с доски | `oly-tasks-autostart`, `oly-tasks-launch-board` — `1/0`, по умолчанию включены; `oly-tasks-launch-wt` — `1/0`, по умолчанию выключен. `oly-tasks-launch-mode` — пять ID из 10, по умолчанию `default`. `oly-tasks-view` — `board/list`, `oly-tasks-mdmode` — `edit/view`, `oly-tasks-sel` — `all/p:<id>/g:<id>`. `oly-tasks-launch-pending` — JSON-массив привязок запусков. | Оставлен. | 40-files | Скачивание файла, ZIP папки, иконка проекта с диска | `oly-files-mode=t3` — доступ через T3; отсутствующий ключ — автоматический выбор локального диска, T3 или SSH | Переключается модуль со всеми его командами. Способ скачивания применяется со следующей загрузки. Для ZIP нужен файловый сервис. |
| 55-composer | Общий разбор и вставка ссылок, чипы и меню упоминаний | Записывает режим из шаблона в ключ модуля 10. Собственного глобального переключателя нет. | Оставлен. 50 и 70 используют его API выбора категории и вставки. При отключении теряются упоминания машин и моделей. |
| 50-machines | Псевдонимы машин и упоминания в сообщении | `oly-machines-aliases` — JSON-объект исходное имя → псевдоним, до 80 символов; `oly-machines-known` — JSON-массив кэшированных машин. | Оставлен. «Имена машин в упоминаниях» открывает штатный редактор в подключениях. | 60-studio | Доски и WordPress в правой панели | `oly-studio-runtime` — `server/desktop` или авто при отсутствии. `oly-studio-client` — адресат событий сервиса | Связан с 92 и сервисом Studio. Оставлен. Это параметры среды предпросмотра. |
| 70-openrouter | Выбор модели из меню упоминаний | `oly-openrouter-filter` — JSON-строка `all/text/image/video/speech/transcription/audio/decision`; `oly-openrouter-recent` — JSON-массив ID; `oly-openrouter-catalog-v3` — JSON с временем и списком моделей. | Требует 55 для вставки. | 80-integrations | Доступ к настройкам интеграций и ключей | Настройки локального сервиса | Точка перехода из бюджета и других панелей. Оставлен. |
| 87-ru-fixes | Русские формы и подписи | Нет | Часть перевода. Оставлен. |

| runtime-translator | Перевод динамического интерфейса | Встроенный словарь | Отдельная часть локализации после сборки. Оставлена. |

Кэши, статистика, прочитанные уведомления и привязки к отдельным тредам не перезаписываются при переключении модулей. Тест `node --test chronos/scripts/olympus-settings.test.mjs` сверяет байты всех блоков, проверяет снимок флагов, зависимости и исходные форматы настроек. На экране внешнего вида в smoke проверяются русские названия и включённое состояние двух основных переключателей.
